# ONLINE BANKING SYSTEM

## Introduction

This is a console-based Online Banking System that provides access to various banking operations.

JDBC has been used to develop this system, including JDBC drivers, database connections, DAO implementations, and exception handling. MySQL is used as the database.

## Tech Stack

- Java
- JDBC
- MySQL
- MySQL Connector/J

## Features

### Accountant

- Accountant Login / Logout
- Create Customer Account
- Update Customer Account
- Delete Customer Account
- Remove Account
- View Customer Details
- View Transactions

### Customer

- Customer Login / Logout
- View Balance
- Deposit Money
- Withdraw Money
- Transfer Money
- View Transaction History
